# Kassa

POS-программа учёта для маленького магазина. Веб, работает в браузере.
Полное ТЗ — в [docs/TZ.md](docs/TZ.md).

## Стек
- **web/** — фронтенд: React + Vite + TypeScript, PWA, локальное хранилище Dexie (IndexedDB).
  Истина живёт на устройстве кассы, чек не теряется при обрыве сети.
- **server/** — бэкенд: Node + Express + PostgreSQL + WebSocket (realtime для кабинета владельца).

## Две раскладки под роли (п.3 ТЗ)
- **Десктоп (от 900px) — касса на ноутбуке/ПК:** боковое меню, продажа в две колонки
  (чек слева, сумма и оплата всегда справа), горячие клавиши `F2` — оплата, `Esc` — закрыть.
- **Телефон — владелец:** нижние вкладки, оплата модальным окном.

## Что готово
- **Этап 1 — Товары + склад + приём:**
  - карточка товара (штрихкод, название, категория, цена продажи/закупки, остаток, мин. остаток);
  - приём по скану: остаток растёт, себестоимость — средняя скользящая;
  - заведение нового товара при приёме (скан → название из внешней базы → цены руками);
  - экран «Товары» с поиском и правкой цен/минимума;
  - журнал действий и обновления в реальном времени по WebSocket.
- **Этап 2 — Продажа + списание:**
  - экран «Продажа»: скан → товар в чек, счётчик количества, итог;
  - открытый чек хранится локально (Dexie) — не теряется при перезагрузке/обрыве;
  - цифровая клавиатура для количества и суммы наличных, расчёт сдачи;
  - оплата наличными/картой, списание остатка, маржа (себестоимость на момент продажи);
  - возврат/обмен: товар на склад, деньги из кассы, запись в журнал;
  - отмена позиции пишется в журнал; идемпотентность чека при повторной отправке.
- **Этап 3 — Роли и права:**
  - вход по логину и PIN (токен хранится на устройстве);
  - владелец видит всё (Продажа, Приём, Товары, Сотрудники); кассир — только Продажа и Приём;
  - кассир не создаёт товары/не меняет цены, не видит выручку и журнал (сервер отдаёт 403);
  - экран «Сотрудники»: владелец заводит кассиров, блокирует, меняет PIN;
  - действия привязываются к пользователю из токена (не из тела запроса).

- **Этап 4 — Смена + сверка кассы:**
  - кассир открывает смену (размен) и закрывает (фактически посчитанные деньги);
  - система считает «ожидается в кассе» = размен + продажи наличными − возвраты;
  - расхождение (недостача/излишек) считается и пишется в журнал;
  - без открытой смены продавать нельзя; продажи/возвраты привязаны к смене;
  - владелец видит все смены и расхождения, кассир — только свои.

- **Этап 5 — Кабинет владельца в реальном времени:**
  - выручка, маржа, чеки, наличные/карта, возвраты за период (сегодня/неделя/месяц/всё);
  - топ товаров по выручке с маржой, последние чеки (кто и когда пробил);
  - остатки по всем товарам с закупочными ценами и подсветкой «пора закупить»;
  - журнал всех действий человекочитаемо, расхождения по кассе выделены;
  - всё обновляется само по WebSocket — без перезагрузки страницы.

- **Этап 6 — Аналитика и инструменты:**
  - «Пора закупить»: остаток на минимуме или ниже, расход за 30 дней, на сколько хватит;
  - «Залежалый товар»: что давно не продаётся (порог 14/30/60/90 дней) и сколько денег заморожено;
  - инвентаризация: скан → фактическое количество, недостача и её стоимость,
    опционально привести остатки к посчитанным; история пересчётов;
  - массовая смена цен по категории (на процент или задать значение), каждое
    изменение пишется в журнал.

### Вход по умолчанию
Логин `owner`, PIN `1234` (создаётся `npm run seed`). Смените PIN после первого входа
на экране «Сотрудники». Задайте свой `JWT_SECRET` в `server/.env`.

## Как запустить (на рабочем компе)

Нужны Node 18+ и PostgreSQL.

### 1. База данных
```bash
createdb kassa
```

### 2. Сервер
```bash
cd server
npm install
cp .env.example .env      # при необходимости поправь DATABASE_URL
npm run migrate           # создать таблицы
npm run seed              # создать пользователя-владельца
npm start                 # http://localhost:4000
```

### 3. Фронтенд
```bash
cd web
npm install
npm run dev               # http://localhost:5173
```

Открой http://localhost:5173 в браузере. Vite настроен на доступ по локальной
сети (`host: true`) — с телефона в той же сети открой `http://<IP-компа>:5173`.

## Переменные окружения (server/.env)
- `PORT` — порт сервера (по умолчанию 4000).
- `DATABASE_URL` — строка подключения к Postgres.
- `BARCODE_LOOKUP_URL` — URL внешней базы штрихкодов с плейсхолдером `{barcode}`.
  Если пусто — название нового товара вводится вручную.
